# 🏫 Bullworth Academy - Sitio Web Informativo

¡Bienvenido al portal oficial de atención al estudiante y turismo de **Bullworth Academy** (basado en el videojuego *Bully* / *Canis Canem Edit*)!

Este proyecto es una página web estática desarrollada para la materia de **Lenguaje Informático**, donde se recrea de forma interactiva y ficticia la guía de la ciudad y del campus universitario/escolar.

---

## 📌 Contenido del Sitio

El sitio consta de las siguientes páginas:

* `index.html`: Página principal e inicio de la academia.
* `ciudad.html`: Información sobre la ciudad de Bullworth y sus zonas.
* `lugares.html`: Puntos de interés y lugares clave para visitantes y estudiantes.
* `contacto.html`: Información de contacto ficticia, atención al alumno y reporte de quejas.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructuración semántica de las páginas.
* **CSS3**: Estilos visuales y diseño responsive.
* **Bootstrap:** marco de desarrollo web front-end gratuito y de código abierto que se utiliza para crear sitios web, aplicaciones responsivas y optimizada
* **Git & GitHub**: Control de versiones y alojamiento del código fuente.
* **Geminis**: Para redactar y escribir este Readme.
